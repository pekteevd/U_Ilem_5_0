# Координатная привязка объектов · У Илем 5.0

## Источники
- Рабочий фон: `U_Ilem_map_empty.png`, Git blob SHA `201a8d9b569b0246a8aaa787be75fb80b495593a`.
- Только визуальный пример: `U_Ilem_map.png`, Git blob SHA `f2a308f101daaab0d010f13d1127f331929ba2b0`.
- Иные файлы карт в runtime не использовать.

## Система координат
- Координаты объектов хранятся в `world-data.js` в `position.x` / `position.y`.
- Значения нормализованы в диапазон 0..1.
- `(0,0)` соответствует верхнему левому углу изображения.
- X увеличивается вправо, Y увеличивается вниз.
- Ширина игрового мира: 100 единиц; высота выводится из фактической пропорции PNG.
- Перевод UV в мировые координаты выполняет только `WorldRenderer.mapPoint()`.

Координаты выше являются текущими рабочими UV-якорями в единой системе карты. Они сохранены от имеющейся модели мира и не считаются пиксельно проверенными по новому изображению до визуального осмотра сцены в браузере. Для ручной коррекции менять значения только в `world-data.js`, не создавать независимые смещения в renderer и UI.

## Правила
1. PNG карты не редактировать и не запекать в него 3D-объекты.
2. Карта-пример со зданиями не загружается в runtime.
3. Габариты построек задаются в мировых единицах в `dimensions`.
4. Любой новый объект получает уникальный ID, тип геометрической модели, UV-позицию и габариты.
5. При добавлении/перемещении модели проверять границы карты, пересечения footprints, дороги, водоём, берег и другие ориентиры.
