## 0002 · 4 ноября 2026 · Статический аудит модулей 4.0

### Проверено
- README и технический отчёт 4.0.
- Сервер/загрузчик, базовая HTML-страница, карта.
- Модули строительства, экологии, интерьеров, освещения, производства и воды.
- Тестовые файлы пяти подсистем.

### Вывод
- 4.0 содержит полезные прототипы хозяйственных подсистем, но основана на монолитной HTML-копии 3.2.
- Модули используют глобальное состояние `G`, глобальные функции и DOM напрямую.
- Общая карта пока не является полноценной 3D-сценой: новые постройки, растения и изделия описаны в техническом отчёте как координатные маркеры поверх изображения.
- Позиции ряда систем рассчитываются в процентах DOM-контейнера.
- Режимы размещения отменяются друг другом вручную.
- Сервер собирает страницу строковыми заменами.
- В репозитории присутствуют тесты для стройки (11), экологии (10), интерьеров (11), производства (12), воды (17), но в этой сессии они не запускались.
- Полный аудит ядра 3.2 (задачи, календарь, персонажи, экономика, чат) ещё впереди.

### Решение для 5.0
Не переносить монолитную HTML-оболочку. Создать новую сцену, единый слой данных/команд, систему координат мира, общий менеджер размещения и явную сборку. Переносить из 4.0 только отдельные правила и расчёты после тестирования.

### Документ
`АУДИТ_ИСХОДНИКОВ_4_0.md`.

### Проверка
Статический анализ файлов. Тесты и браузерный запуск не выполнялись.

## 0003 · 4 ноября 2026 · Аудит интеграции Ollama и командного чата

### Проверено
- `U_Ilem_4_0_server.js`: API здоровья Ollama, список моделей и endpoint чата.
- `U_Ilem_4_0.html`: стартовый редирект.
- `U_Ilem_4_0_base.html`: функция `sendCommand()`, создание сообщений и задач.

### Результат
- Серверный endpoint `/api/ollama/chat` существует, модель зафиксирована как `qwen3:4b`.
- Клиентский `sendCommand()` не вызывает endpoint Ollama. Вместо этого используются регулярные выражения и заранее заданные шаблоны задач.
- Поэтому старый командный чат не был реально подключён к Ollama на уровне клиентского игрового сценария. Это подтверждённая причина, а не предположение о качестве модели.
- Сервер принимает произвольный JSON и пересылает его в Ollama; строгой схемы ответа и валидатора игровых команд нет.
- Наличие endpoint не гарантирует установленную модель; runtime-проверка на компьютере пользователя не выполнялась.

### Решение для 5.0
Отдельный AI adapter с health/model check, ограниченным контекстом, нормализованной схемой предложений и доменным валидатором. ИИ не имеет прямого доступа к WorldState. Все изменения выполняются только через подтверждённые пользователем доменные команды. Отсутствие Ollama не блокирует базовую игру.

### Статус проверки
Статический аудит исходников. Ollama и браузерный сценарий не запускались.

### Следующий шаг
Закончить сверку открытых требований и зафиксировать автономный технологический стек 5.0. Затем создать первый исполняемый вертикальный срез: локальный запуск, точная карта, объёмная сцена, выбор объекта, карточка объекта, единая задача и сохранение.

### Следующая реализация
