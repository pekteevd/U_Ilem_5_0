## Принципы
- Новая архитектура, не косметический патч 4.0.
- Windows, локальный запуск.
- Телефон отложен.
- Godot не используется.
- Утверждённая карта не заменяется и не запрашивается повторно.
- Один основной комплект файлов, без множества параллельных версий.
- Проверка кода не выдаётся за проверку игры в браузере.

## Первый запуск на Windows
1. Скачай репозиторий и открой папку `U_Ilem_5_0`.
2. Убедись, что установлен Node.js 18 или новее.
3. Запусти `START_U_ILEM_5_0.bat`.
4. Должна открыться страница `http://127.0.0.1:4175`. Окно консоли сервера оставь открытым, пока игра запущена.
5. Сохранения создаются в локальной папке `data/`; резервная копия предыдущего сохранения создаётся автоматически.

Файл запуска: [START_U_ILEM_5_0.bat](START_U_ILEM_5_0.bat). Основная карта: [U_Ilem_5_0_visual_base.png](U_Ilem_5_0_visual_base.png).

**Статус: первый runtime-каркас создан.** В каталоге уже есть локальный Three.js r180, карта, WebGL-сцена с объёмными объектами, камера, карточки объектов, общая модель задач/календаря, базовый склад/экономика, сохранение и локальный Node.js-сервер с BAT-запуском.
