# Аудит сцены и привязки объектов · У Илем 5.0

Дата: 4 ноября 2026 года

## Проверено

### Загрузка карты
- `world-renderer.js` загружает `./U_Ilem_5_0_visual_base.png` через Three.js TextureLoader.
- Текстура переводится в SRGB, настраивается anisotropy, создаётся плоскость с пропорциями фактического изображения.
- Камера подгоняется под фактический aspect ratio после успешной загрузки текстуры.
- Ошибка загрузки не скрывается: пользователь видит сообщение в области карты.
- Путь карты локальный, CDN для изображения не используется.

### Координатная модель
- Позиции объектов задаются нормализованными координатами x/y в диапазоне 0..1.
- `mapPoint()` переводит их в мировые координаты с учётом ширины и вычисленной высоты карты.
- CSS-контейнер сцены имеет пропорции 1648:928, совпадающие с заявленным форматом базового изображения в интерфейсе.
- Восемь объектов мира находятся внутри границ нормализованной карты.
- Проверка осевых bounding-box по текущим позициям и габаритам: 0 пересечений между восемью объектами.
- Выбор объекта выполняется raycaster-ом по дочерним mesh, каждый mesh получает objectId.
- Синхронизация персонажей берёт только задачи со статусом `in_progress`, назначенным исполнителем и существующим объектом. Модели персонажей статичны.

### Камера и ввод
- Есть zoom in/out, wheel zoom, drag pan, reset и focus selected object.
- Изменение размера viewport обновляет размеры renderer и frustum камеры.
- Обработчики pointer cancel и pointer capture предусмотрены.
